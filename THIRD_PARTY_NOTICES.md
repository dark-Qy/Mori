# Third-Party Notices

This file records required attribution and license notices for third-party code and assets distributed with Watch Companion.

## Current status

No third-party source package, font, sound, illustration, pet artwork, or model asset is bundled at repository initialization.

Apple platform SDKs are referenced through Xcode and are governed by Apple's applicable license agreements; they are not redistributed by this repository.

## Contributor requirement

Before adding a dependency or asset, record:

- name and version or revision;
- canonical source URL;
- copyright holder;
- license and a link or copy of its text;
- whether attribution must appear in the application;
- where the dependency or asset is distributed;
- privacy, telemetry, and network behavior;
- reason it is preferable to a platform API or local implementation.

Do not add code, media, generated artwork, datasets, model output, or fonts whose redistribution rights are unknown. AI-generated assets require provenance notes and must be checked for third-party trademarks and recognizable protected characters.
